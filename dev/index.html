PkgBump

Documentation for PkgBump.

Description

PkgBump.jl automatically increments the version in a Julia Project file. Package developers only have to run one of the three functions:

# Roughly speaking
bumppatch: v"x.y.z" -> v"x.y.(z+1)"
bumpminor: v"x.y.z" -> v"x.(y+1).0"
bumpmajor: v"x.y.z" -> v"(x+1).0.0"

Internally, we use the Base.nextpatch, Base.nextminor, Base.nextmajor functions respectively.

PkgBump.registerpatch — Method
registerpatch(; poll_interval=10, timeout=3600, merge_method=:squash)

Bump the active package's patch version, create and automatically merge a PR, then request registration on its merge commit using the authenticated gh user. Returns the PR URL. Requires a clean checkout of the default branch, gh authentication, Registrator, and auto-merge enabled on the repository. If the wait times out, the PR may still merge and registration must be requested manually.
